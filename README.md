# Javidh — Analytics Portfolio

Personal portfolio website for Kovvuru Javidh, an Assistant Branch Postmaster at India Post and aspiring Data Analyst.

The site presents analytics projects, skills, experience, resume, and contact links through a warm, rounded, animated interface inspired by Claude and macOS design language.

## Highlights

- Responsive Next.js portfolio experience
- Animated ambient background and scroll-reactive motion
- GitHub-backed project previews and live project links
- Skills, experience, selected projects, resume, and contact sections
- Accessible reduced-motion support and mobile-friendly navigation

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build

```bash
npm run build
```
